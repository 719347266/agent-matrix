# 核对「关于你」有没有变化

## 要交出什么

当前文件夹的 `profile-updates.json`。没有实质变化就写 `{"changes": []}`，这是正常结果。

## 输入

已确认的「关于你」：

{current}

允许查看的来源：{sources}。各来源的核对起点：{since}。只看起点之后的变化。

## 怎么查

- 优先用选定来源里已有的本地记录；每个选定的远程来源最多查一次，限定日期和相关项目。找不到新的具体事实就结束。
- 只收**改变了对本人认识**的具体事实。换个说法、重复印证、一次性的待办都跳过。本人明确写下的偏好优先。
- 不保存原文、密钥或私人聊天细节。

## 输出格式

```json
{"changes": [{"type": "profile", "old": "旧句", "new": "更新后的句子", "why": "哪条新证据、哪天、改变了什么"}]}
```

- 最多两处。
- 细化已有内容：`old` 原样摘录一处能唯一定位的原文，`new` 只写替换它的文字。
- 真正新增的认识尽量补进对应段落；现有段落都不合适，才新增一个小节（`old` 留空）。
