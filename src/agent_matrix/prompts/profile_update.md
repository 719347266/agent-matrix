# 核对「关于你」的变化

已确认的内容如下：

{current}

本次允许查看的来源为 {sources}。各来源的核对起点为 {since}。只看这些起点之后的变化。优先用选定来源中已有的本地记录；每个选定的远程来源最多查询一次，限定日期及相关项目。找不到新的具体事实就结束。不改外部资料，不保存原文、密钥或私人聊天细节。

在当前目录写 profile-updates.json。已有事实需要细化时，old 原样摘录一处可唯一定位的原文，new 只写它的替换文字。真正新增的认识尽量补入对应段落；只有现有段落都不适用才新增一个小节。why 写出具体依据、日期和究竟变了什么。本人明确写下的偏好优先。换个说法、重复印证或一次性的待办都跳过。

最多两处。没有实质变化就写 {"changes": []}。有变化时的格式为 {"changes": [{"type":"profile","old":"旧句","new":"更新后的句子","why":"哪条新证据改变了这句话"}]}。写完提交。
