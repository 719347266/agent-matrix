# 方案：资深的方案负责人会怎么写

## 结构
1. 结论先行：推荐哪个、为什么、要谁拍板什么。
2. 背景和约束：要解决什么、时间 / 人力 / 预算 / 技术的限制。
3. 选项：两到三个真正可选的做法，每个写清怎么做、要多少成本、风险是什么。
4. 对比和推荐理由：按同一组标准对比；推荐的理由要能被反驳。
5. 怎么推进：分几步、谁做、什么时候看到结果、怎么判断成功。
6. 待拍板：需要决定的点和建议。

## 写法
- 选项要真实可选，不放凑数的选项。
- 成本、时间、数据有出处或写明是估计。

## 检查清单
- 第一屏就能看到推荐和要拍板的事
- 每个选项都有成本和风险
- 推荐理由和对比标准一致
- 有下一步和判断成功的标准
- 没有凭空的数字；估计的写明是估计
