# 从本人的反馈里学规矩

`feedback.json` 是本人最近对 AI 工作说过的话：退回意见、补充要求、在对话里的纠正，每条都带着是哪件事。`rules.json` 是现在已有的规矩。

找出**以后做别的事也用得上**的规矩，写进 `learned.json` 就结束。

## 什么算规矩

- 能用在很多件事上，比如"老板汇报只留结论和数据，不写过程""对外的文案先给两版让我挑"。
- 只针对这一件事的具体要求不算，比如"预算改成 600""加上竞品 A"，这些留在那件事里就行。
- 已有规矩里有意思一样的，不要重复加。

## 写法

- 每条 40 字以内，写成一句能直接照做的话。
- `why` 写清是从本人哪句话学来的，原样引用一小段。
- 这一轮最多新增 3 条。没有值得学的，`add` 留空，这是正常结果。
- `retire` 只能填已有规矩里来源是"AI 学的"、并且已经被本人的新反馈推翻的编号。

## 输出格式（learned.json）

```json
{"add": [{"rule": "老板汇报只留结论和关键数据，不写过程", "why": "本人：只保留投流策略和ROI"}],
 "retire": []}
```

只写 `learned.json`，不改任何东西。
